추가 파티클 효과는 이번 핵심 촬영에서 제외한다. 스테이지 클리어 강화 아이템은 구현·자동 검사를 마쳤으므로 전체 플레이 영상에서 2개 드롭→이동해서 직접 획득→다음 스테이지 진입을 담는다. 화면 밖으로 놓친 아이템은 소멸한다. 필요하면 `stage-reward.gif`로 발췌하고 HUD의 DMG/BURST/SHOT INTERVAL 변화를 함께 보여준다. 실제 녹화는 아직 하지 않았다.

## 촬영 순서

1. 전체 플레이와 최종보스 두 페이즈를 녹화한다. 요약·대표 GIF·스테이지 사진·적 디졸브·배경·체력바를 여기서 추출한다.
2. 플레이어 사망과 좌우 이동을 짧게 추가 녹화한다.
3. F1 패널을 열고 F5 전환을 촬영한다. 일시정지 중 전환하면 후보 수가0으로 초기화되므로 재개한 뒤 실제 값을 보여준다.
4. 렌더 비교 벤치마크를 녹화하고 최종보스의 같은 반복 두 구간을 추출한다. 녹화 중 CSV는 시연용이며 기존 공식 CSV를 덮어쓰지 않는다.
5. ComfyUI 원본 이미지·생성 영상·추출 프레임·시트를 모아 제작 과정 자료를 만든다.

## 촬영 설정

- Release / client1920×1080 / 기본 숲·안개. 게임 창 영역으로 크롭하고 작업 표시줄·편집기는 제외한다.
- 일반 플레이에는 BGM·효과음을 담는다. 자동 벤치마크는 BGM OFF이다.
- 원본은1080p/60fps로 보관하고 GIF는 필요한 영역만 크롭한다. 긴 영상은 링크/임베드, 짧은 효과는 GIF 또는MP4로 넣는다.
- F1은 소개 장면에서 숨기고 후보 비교에서 표시한다. F6는 무적, F4는 전체 적에게50데미지다. 무적은 재시작에도 유지되므로 사망 촬영 전에 끈다.
- 렌더 비교는 개별/인스턴스 경로를 사용한다. B키의 효과ON/OFF는 후광까지 바뀌므로 렌더 전후 비교에 사용하지 않는다.
- 단위 유지: 풀2.492→0.690ms는5초 합계, Grid20.69→21.84µs는고정 업데이트1틱, 렌더1.540→0.559ms는프레임 시간이다.
